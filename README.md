# tz_template — тестовый игровой проект

Прототип игры «Angry Birds»-стиля: натягивание резинки, выстрел, разрушение блоков (Matter.js).

## Запуск

- **Игра:** `http://127.0.0.1/projects/tz_template/`
- **Редактор:** `http://127.0.0.1/eeditor/` → проект `tz_template`

## Структура

| Путь | Назначение |
|------|------------|
| `src/main.js` | Геймплей, меню, переключение уровней, очки и звёзды |
| `src/loading.js` | Загрузка ресурсов и старт игры |
| `layouts/` | UI и уровни (JSON) |
| `lang/` | Локализация (ru, en) |
| `project.json` | Список ресурсов и сборка |

## Игровой поток

```
Старт → сразу level_1 (игра)
     → из win / кнопок можно открыть меню (menu) и выбрать уровень 1 / 2 / 3
     → игра (level_1 / level_2 / level_3), максимум 3 броска
     → победа: все блоки разрушены → win (очки + звёзды)
        или поражение: 3 броска израсходованы, блоки остались → win (надпись «Вы проиграли»)
     → «Следующий уровень» / «Начать заново» / «В меню»
```

## Журнал изменений

Краткие пояснения к доработкам проекта.

### Переключение уровней (`src/main.js`)

- **`loadLevel(layoutName)`** — через `teardownLevel()` снимает текущий уровень и отменяет отложенные таймеры, загружает layout (`level_1`, `level_2`, `level_3`), подключает управление и физику блоков.
- **`teardownLevel()` / `clearLevelTimeouts()`** — удаляют узел уровня и гасят `loseCheck` / `settle` / `winResult`; **`levelEpoch`** отсекает колбэки от старого уровня (иначе после победы и next level мог сработать старый lose-таймер).
- **`currentLevelName`** — имя активного уровня.
- **`levelOrder`** — порядок уровней: 1 → 2 → 3.
- **`getLevelAliasesData()`** — общая логика резинки и выстрела для всех уровней.
- **`initLevelBlocks()`** — помечает нестатичные тела как разрушаемые (100 HP), сохраняет `totalBlocks`.
- **`setupCollisionHandler()`** — один раз подписывается на `collisionStart`; перед этим вызывает `initPhysics()`, иначе `ph_Events` ещё не создан.

### Главное меню

- **`layouts/menu.json`** — экран выбора уровня; узлы `btn_level_1`, `btn_level_2`, `btn_level_3`.
- **`show_menu()`** — открывает окно `menu`, по нажатию вызывает `loadLevel(...)` и закрывает меню.
- **Старт игры** — при `__ON_GAME_LOADED` сразу вызывается `loadLevel(currentLevelName)` (`level_1`). Меню открывается по кнопке «В меню» с экрана win (и при необходимости из кода).
- **`project.json`** — в `res` → `layout` добавлен `menu.json`.
- **`layouts/menu.json`** — у корня задан `"name": "menu"` (обязательно для `showWindow('menu')`).

### Прогресс, блокировка уровней и звёзды в меню

Прогресс хранится в переменной `sessionProgress` в памяти (только на текущую сессию вкладки; сбрасывается при F5 / закрытии): число звёзд `0…3` за каждый уровень.

| Функция | Назначение |
|---------|------------|
| `loadProgress()` / `saveProgress()` | чтение / запись `sessionProgress` (`{ level_1, level_2, level_3 }`) |
| `isLevelUnlocked(name)` | уровень 1 всегда открыт; следующий — только если у предыдущего звёзды `> 0` |
| `saveLevelResult(name, stars)` | при победе сохраняет лучший результат |
| `updateMenuLevelVisuals(wnd)` | затемняет и `__disabled` для закрытых уровней; над кнопкой показывает заработанные звёзды (`star2.png`) |

- Закрытый уровень: `__alpha: 0.35`, тап не срабатывает.
- Звёзды над кнопкой: сколько набрано (0 — ничего не рисуется).
- Кнопка «Следующий уровень» на экране победы ведёт только на реально открытый следующий уровень.

### Экран победы / поражения (`layouts/win.json` + `main.js`)

Один layout `win` используется и для победы, и для поражения; содержимое настраивается в `show_result(isVictory)`.

- **`title`** — `you_win` или `you_lose`.
- **`next_level`** — при победе: следующий уровень (скрыта на `level_3`); при поражении: **«Начать заново»** (`restart`) → `loadLevel(currentLevelName)`.
- **`btn_menu`** — возврат в главное меню.
- **`score`** / **`stars`** — только при победе; при поражении скрыты.
- Layout: узел `button` → `next_level` (имя должно совпадать с кодом в `__setAliasesData`).

### Лимит бросков и поражение (`src/main.js`)

| Константа / флаг | Назначение |
|------------------|------------|
| `MAX_SHOTS` | `3` — максимум бросков на уровень |
| `LOSE_CHECK_DELAY` | пауза после 3-го броска (`BULLET_LIFETIME + 0.5`), чтобы успела отработать физика |
| `levelEnded` | защита от повторного показа окна и лишних выстрелов |
| `canShoot()` | `false`, если уровень завершён, броски кончились или открыто окно |

- После каждого выстрела `shotsCount++`; при `shotsCount >= MAX_SHOTS` вызывается `scheduleLoseCheck()`.
- Если за отведённое время блоки ещё есть → `show_result(0)` (поражение).
- Если все блоки разрушены раньше → `show_result(1)` (победа), проверка поражения пропускается.
- При поражении играет `lose` (`sounds/lose.mp3`); при победе — `win`.

### Счётчик шаров (попыток) на уровне

На каждом уровне в layout есть узел **`shots_hud`** с детьми `ball_0` … `ball_2` (иконка `circle1`).

При загрузке `createShotsHud()` берёт этот узел из layout; если его нет — создаёт запасной в коде. После каждого броска `updateShotsHud()` скрывает израсходованные шары (`remaining = MAX_SHOTS - shotsCount`).

#### Как изменить

| Что | Где |
|-----|-----|
| Позиция на экране | В редакторе узел `shots_hud` → `__ofs` (сейчас `[-500, -300, 50]` — левый верх) |
| Размер иконок | У `ball_0` / `ball_1` / `ball_2` → `__size` |
| Расстояние между шарами | `__ofs.x` у `ball_1`, `ball_2` (шаг 56) |
| Картинка | `__img` у шаров (сейчас `circle1`; положите свою в `img/` и пересоберите атлас) |
| Число попыток | `MAX_SHOTS` в `src/main.js` **и** столько же узлов `ball_N` в layout |

Файлы layout: `layouts/level_1.json`, `level_2.json`, `level_3.json`.

### Система очков и звёзд (`src/main.js`)

Счётчик сбрасывается при `loadLevel()` и при возврате в меню.

| Переменная / константа | Назначение |
|------------------------|------------|
| `shotsCount` | Число выстрелов за уровень (инкремент в `__dragEnd`) |
| `totalBlocks` | Число больших блоков на старте уровня |
| `SCORE_PER_BLOCK` | `1000` — база за каждый блок |
| `SCORE_PER_EFFICIENCY` | `500` — бонус за неиспользованные броски |
| `lastScore` / `lastStars` | Результат последнего прохождения |

**Формула очков (только победа):**

```
score = totalBlocks * 1000 + (MAX_SHOTS - shotsCount) * 500
```

**Звёзды при победе** (`clamp` в диапазон 1…3):

| Бросков | Звёзды |
|---------|--------|
| 0 | 3 |
| 1 | 3 |
| 2 | 2 |
| 3 | 1 |

**Отображение на `win`:**

- `calcScoreAndStars()` — считает `lastScore` и `lastStars` перед показом окна победы.
- Узел `score` получает текст через `TR('score') + ': ' + lastScore`.
- `applyWinStars()` — прячет незаработанные звёзды (`__visible = 0`, `__scaleF = 0`). Порядок: центр → правая → левая.

### Небо и атлас (`project.json` + `img/`)

Тяжёлые фоны **не** пакуются в атлас (JPG перекодировался бы в огромный PNG).

| Ресурс | Как хранится |
|--------|----------------|
| `simplesky.jpg`, `darksky.jpg`, `seasky.jpg` | отдельные `["image", "img/…"]` в `res`; в layout — `__img: "….jpg"` |
| UI / блоки / облака (`*.png`) | атлас: ATLAS `src` = `./img/*.png` → `build_res/atlas-0.*` |

- В `datacache` добавлен `"img/*.jpg"`, чтобы production-сборка инлайнила неба.
- Рекомендуемый размер неба ≈ разрешение игры / Full HD (darksky ужат до 1920×1080).
- После смены картинок: `make ATLAS` (или пересборка атласа), при полном билде — `make ALL`.

## Как добавить кнопку на layout

1. В редакторе: выделить родителя → **Insert** → задать **имя** узла (alias).
2. Свойства: `__size`, `__ofs`, `__img` / `__color`, `__text.__text` (ключ из `lang/`).
3. Для статичного UI: **`__scaleF: 1`** (без анимации).
4. В `main.js` в `__setAliasesData({ ... })` добавить обработчик:

```javascript
имя_узла: {
    __onTap() { /* действие */ },
    __onTapHighlight: 1
}
```

Имя в layout и в коде должно совпадать.

## Как добавить новый уровень

1. Скопировать или создать `layouts/level_N.json` в редакторе.
2. Добавить `"level_N.json"` в `project.json` → `res` → `layout`.
3. Добавить `'level_N'` в `levelOrder` в `main.js`.
4. При необходимости — кнопку в `menu.json` и обработчик в `show_menu()`.
